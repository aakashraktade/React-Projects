# React + Vite
Contact Us Page 🚀

This project is a Contact Us Page built using React + Vite.
It provides multiple ways for users to get in touch, including support chat, call, and email form.

🛠️ Tech Stack

React (Frontend UI)

Vite (Fast bundler & dev server)

Styled Components / CSS for styling
